# Labs (not built)

`MenuBarControl.swift.txt` is the macOS 27 icon-hiding bridge from the first Vitals prototype. It relies on
Apple's private `MenuBarClientCore` framework and the exam "assessment mode" allowlist (which can block
Notification Center). It is kept for reference only and is not part of the app target.

Rename it back to `.swift` inside `Vitals/` to experiment. Third-party notice: `ThirdPartyNotices.txt`.
